# Fios Turquesa

Primeira versão do site da loja de crochê Fios Turquesa, de Curitiba e região.

## Abrir no computador

Abra `index.html` no navegador. Mantenha `style.css` e a pasta `assets` no mesmo local.

## Enviar ao GitHub

1. Crie um repositório chamado `fios-turquesa`. Para usar GitHub Pages com uma conta GitHub Free, escolha um repositório público.
2. Extraia o ZIP deste projeto.
3. Na página do repositório, escolha **Add file → Upload files**.
4. Arraste o conteúdo da pasta extraída para a área de upload: `index.html`, `style.css`, `README.md` e a pasta `assets`. Inclua `.nojekyll` se estiver visível.
5. Salve os arquivos na branch `main` pelo botão de confirmação mostrado pelo GitHub.

Importante: `index.html` precisa estar na raiz do repositório, ao lado de `style.css`. Não envie apenas o ZIP nem uma pasta externa contendo todo o projeto.

## Colocar no ar com GitHub Pages

1. Acesse **Settings → Pages** no repositório.
2. Em **Build and deployment → Source**, selecione **Deploy from a branch**.
3. Selecione a branch `main` e a pasta **/(root)**.
4. Clique em **Save**.
5. Aguarde a publicação. O endereço será exibido nessa tela.

Ao atualizar os arquivos da branch selecionada, o GitHub Pages publica a nova versão.

Referências oficiais:

- [Enviar arquivos](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)
- [Configurar o GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Onde fazer alterações

- `index.html`: textos, seções, navegação e links.
- `style.css`: cores, fontes, espaçamento e adaptação a celular.
- `assets/logo.png`: logo fornecida pela família.
- `assets/blusa.png`: foto da blusa fornecida pela família.

Não é necessário instalar ferramentas ou fazer uma compilação. Todos os caminhos de imagens e estilos são relativos e funcionam quando o site é publicado dentro de um repositório.

## Estado desta versão

Site de apresentação com contato pelo Instagram. Preço, medidas e disponibilidade são consultados diretamente com a loja. Ainda não há carrinho, pagamento online ou controle de estoque.

Arquivos e referências internas foram conferidos; a aparência no navegador ainda precisa de revisão. A foto da blusa recebida contém pequenos ícones no canto inferior, que poderão ser substituídos por uma foto original da peça.

Traga o link do repositório e descreva as mudanças desejadas. Podemos revisar logo, cores, fontes, textos, fotos, seções e apresentação em celular, preservando esta pasta como base do projeto.
